# /night/ 40곳 원고 파일 작성 가이드 (PAGE_ROUND 3 · 2026-08-16)

원고는 업소당 1파일: `scripts/night40/{slug}.js` (CommonJS `module.exports = {...}`).
표준 예시: `ulsan-champion-1.js` (광고주형) · `jejudo-night-1.js` (위치 확인불가형).
조립은 `scripts/build-night40.js`가 한다. 필드 누락·형식 이탈 시 빌드가 죽는다.

## 필드
- `slug`, `name`, `group`('B'), `hue`(지정값), `keywords`(업소명+지역 조합 4~5개, 쉼표 구분)
- `nameAlt`: 지정된 업소만 (배열), 그 외 생략
- `addr`: `{street, jibun, floor, locality, region, geo}` — 확인된 값만, 미확인은 null
- `landmark`(주소 전무 시 일대 설명), `station`(확인분만), `noRail`(철도 없는 도시 설명 또는 null), `age`(확인분만), `contact: null`
- `title`: **지정값 그대로** (수정 금지)
- `description`: 공백 포함 70~80자. 업소명 또는 동네 고유 디테일 포함. 낚시·과장 금지
- `ogAlt`: `'업소명 소개 카드 — 광고문의 카카오톡 besta12'`
- `ogNameLines`: 지정값. `heroBadge`: `'지역 · 랜드마크'` 형태
- `lead`: 3~4문장. 마지막 문장에 "답은 글 끝에" 계열 예고(표현은 페이지마다 다르게)
- `direct3`: 3줄 배열. `'<strong>위치</strong> — …'`, `'<strong>가는 법</strong> — …'`, `'<strong>특징</strong> — …'`. 확인 사실만. 미확인은 "공개 정보로 확인 불가" 취지를 페이지마다 다른 문장으로
- `sections`: **정확히 5개** `{h2, ps:[문단 2~3], bridge}` (5번째는 bridge 생략).
  - h2 중 **질문형 2개 이상**(~일까/~인가/~는가). 5번째 h2는 제목 훅에 대한 답("그래서, …" 변형)
  - 문단은 2~3문장, 태그 없는 순수 텍스트
- `faq`: **정확히 3개** `{q, a}` — 위치 / 연령·영업시간(미확인이면 정직하게) / 문의·기타
- `oneLine`: 한 줄 정리 1문장
- `links`: 지정된 slug 2개 그대로

## 분량·키워드
- lead+direct3+sections+faq+oneLine 합계 **공백 포함 1,750~2,100자** (조립 후 게이트 1,800~2,500)
- 업소명 정확 표기: lead 1회 + sections 1~2회 + faq 최대 1회 = **본문 합계 2~3회** (h1·표 캡션 자동 +2 → 최종 4~5회). 초과 금지. 나머지는 "이 집", "이 지하" 등으로 변주

## 절대 금지
- 단어: 룸살롱, 룸싸롱, 노래방, 밤문화, 유흥, 2차 (본문·description·FAQ 전체)
- 별점·평점·★, 방문자 수, 잔여석, 후기 인용, 요금·가격, "명이 이번 달"/"자리 남았"/"마감까지"
- 미확인 사실 창작(영업시간 단정, 좌석 수, 층수 추측 등). "자정 무렵", "밤이 깊으면" 같은 일반 시간 표현만 허용
- 전화번호 일체(광고주 3업소 파일 외 어디에도 금지)
- 외부 링크·타 도메인 언급, 자매 사이트 언급
- 다른 페이지와 20자 이상 동일 문장 공유(예시 파일 문장 복사 금지) — 게이트에서 탈락
- 시간표 분석, 전체 Q&A 포맷, 좌석 도감, 부킹 매너 강좌, 교통 내비식 나열, 선택 기준표, 용어사전 각도
